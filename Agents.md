# clone-tabnews-ia

Clone do TabNews (plataforma brasileira de conteúdo sobre tecnologia) implementado com agentes de IA.

## Stack

- Next.js com App Router (código em `app/`)

## Comandos

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm start`: servidor de produção
- `npm run lint`: ESLint (`eslint-config-next/core-web-vitals` + `eslint-config-prettier`)
- `npm run lint:fix`: ESLint com correção automática
- `npm run format`: formata o código com Prettier
- `npm run format:check`: verifica a formatação sem alterar arquivos
